# 💍 我们的浪漫婚礼大屏相册 — Wedding Gallery

一款专为婚礼现场、宴会大屏展示而打造的高品质、电影级 **3D 缓动幻灯片播放与沉浸式背景音乐系统**。基于现代前端技术栈（Vite + React 18 + TypeScript + Tailwind CSS）精心双层架构渲染，开箱即用。

> **🔒 隐私安全保护特别提示**：为了新人照片的隐私安全，本项目已通过 `.gitignore` **自动忽略了 `/src/assets/photos/` 下的所有照片**。您在开发和部署时放入的照片仅存在于您本人的电脑和服务器上，**绝对不会被意外提交、泄露到公共 Git 托管平台**，安全无虞。

---

## ✨ 核心亮点 & 细节设计

### 1. 🎬 电影级画面转场效果
* **丰富的过渡效果选项**：内置 8 种高品质、电影级转场效果，新人可以在现场控制台根据喜好任意切换：
  * **温润漂移 (Ken Burns)**：电影大师级经典变焦，大图随时间轴自适应、极缓慢地多维缩放与移位（自适应用户设定的秒数，完美延展动画），赋予静态照片无穷的空间流动感与故事感。
  * **3D折叠翻页 (flip3D)**：高端立体透视空间卡片旋转，引入 1200px 3D 视距透视（Perspective）与 Y 轴折叠翻转，极具现代轻奢感与奢华感。
  * **滑动淡入 (slideFade)**：将柔和的水平横移与平滑渐变精妙结合，出场与进场交相辉映，比纯滑动更富有浪漫诗意。
  * **电影缩放 (zoom)**：自带有空间纵深感的缓慢缩放与交叉淡入。
  * **经典淡入 (fade)**：最浪漫、高阶纯净的无缝重叠渐变淡入淡出。
  * **横向滑动 / 纵向滑动 (slide / slideV)**：极致丝滑的无卡顿滑动轨道模式。
* **无缝无痕覆盖**：通过独创的双图层淡入机制（Fade-in Overlapping），切换下一张照片时新图层优雅地在旧图层上方淡入，彻底告别传统幻灯片切换时的生硬截断或瞬间白屏。

### 2. 🌸 高性能 Canvas 浪漫粒子系统
* **空气感花瓣雨**：摒弃低效的 DOM 渲染，基于 HTML5 Canvas 2D 物理系统。40 片手绘玫瑰/樱花粉嫩花瓣不仅在 $Y$ 轴下落，还带有基于正弦波算法的微风左右摇曳感。
* **璀璨星尘**：额外在背景中渲染了 15 颗明暗呼吸、缓慢浮动的**金色星尘**，大大提升婚礼现场的唯美与轻奢感（支持随时在控制台一键关闭花瓣雨特效）。

### 3. 🎵 平滑无感听觉体验 (Web Audio Transitions)
* **音频缓入缓出 (Volume Fading)**：播放、暂停、切歌或删除歌曲时，音量会以 50ms 间隔在 `0` 到 `设定音量` 之间进行优雅的抛物线淡入淡出，保护现场宾客听觉。
* **首开拦截自动解锁**：针对现代浏览器“禁止未交互自动播放音频”的限制，系统底层挂载了全局无感交互监听，一旦点击大屏任何地方，背景音乐瞬间无缝解锁。
* **专属音乐库管理**：内置 5 首世界级浪漫古典钢琴/小提琴曲。支持一键添加您本地的 MP3/WAV 婚礼歌曲，并支持置顶排序、删除和随机播放。

### 4. 🖱️ 智能人机交互
* **鼠标 3s 智能隐形**：控制面板支持智能感应。鼠标静止 3 秒自动隐形；一旦移动鼠标，面板即刻丝滑滑出。**在用户悬停控制栏、或正在编辑修改大屏字幕、或点击下拉菜单时，系统会自动锁定并阻止隐藏。**
* **全键盘流线控制**：
  * `Space (空格)`：暂停 / 播放照片幻灯片。
  * `ArrowRight (右方向键)`：手动切到下一张照片。
  * `ArrowLeft (左方向键)`：手动切到上一张照片。
* **全屏极简**：支持一键物理全屏切换，完美适配各种宴会厅 LED 大屏分辨率。

## 🛠️ 技术栈

* **核心框架**：React 18.3.1 (Hooks API)
* **构建工具**：Vite 5.4 + TypeScript 5.5 (极其轻量，极速热更新)
* **样式系统**：Tailwind CSS 3.4 (响应式与自定义 CSS 动画)
* **图标系统**：Lucide React (矢量唯美图标)
* **核心动效**：HTML5 Canvas 2D Animation + CSS3 Keyframes
* **音频控制**：HTML5 Audio API (自定音量缓动控制器)

## 🚀 快速开始

### 1. 克隆或下载本项目
确保您的本地电脑上安装了 [Node.js](https://nodejs.org/)（建议 v18+）。

### 2. 安装依赖
在项目根目录下，使用终端运行：
```bash
npm install
```

### 3. 开启本地开发预览
```bash
npm run dev
```
启动后，浏览器会自动打开 `http://localhost:3000` 并开始播放！

### 4. 编译打包（发布上线或本地离线部署）
```bash
npm run build
```
打包完成后，会生成 `dist/` 静态文件夹。您可以将该文件夹部署到任意静态服务器（GitHub Pages, Vercel, Netlify 或本地内网）。

## 🎨 专属个性化自定指南（新人必看 💍）

### Q1：如何换上我们自己的新婚照片？
1. 打开 `src/assets/photos/` 目录。
2. 将你们的精美婚礼高清照片（建议转为 `.jpg`, `.png` 或 `.webp` 格式，分辨率不限，系统会自动 `object-cover` 裁剪铺满大屏）放入该文件夹。
3. 重新启动服务，系统会自动读取该目录下所有照片进行随机电影级播放。
4. *若您不想修改代码，也可以在大屏运行后，点击控制台最左侧的 **“文件夹” 按钮** 📁，一键选中您电脑里的婚礼照片文件夹，系统会立即开始全屏轮播您刚才选中的照片！*

### Q2：如何修改首屏加载页显示的婚礼标题 / 寄语？
打开 `src/App.tsx` 文件，找到第 20 行：
```typescript
const [titleText] = useState('新郎 何建峰 ❤️ 新娘 周婉情 | 我们结婚啦 💍');
```
将单引号内的文字替换为您和爱人的姓名、婚礼日期或浪漫宣誓，保存即可！首屏加载时将显示这段浪漫的见证文字。

### Q3：如何更换默认的背景音乐？
* **临时追加**：直接在大屏底部的音乐控制器中点击 “添加更多本地婚礼音乐 (MP3/WAV)” ➕ 按钮即可。
* **永久更换（自动检索，零配置）**：
  1. 准备好您的婚礼歌曲文件（支持 `.mp3`, `.wav`, `.flac`, `.aac`, `.ogg`, `.m4a` 等常见音频格式）。
  2. 直接将这些歌曲放入 `src/assets/music/` 目录中（您可以删除原有的默认测试音频）。
  3. **无需修改任何代码**：系统运行时将使用 Vite 的 `import.meta.glob` 自动扫描该目录下的所有音频，以文件名作为歌名自动优雅加载、排序，并自动应用 Content Hash 缓存防冲突技术，开箱即用！
